<section class="term-section">
    <h2>Full Definition</h2>
    <p><strong>Nominal value</strong> (also called face value or par value) is the value assigned to a security by its issuer. For bonds, it represents the principal amount that will be repaid at <a href="/knowledge/glossary/maturity/">maturity</a> and the base for calculating <a href="/knowledge/glossary/coupon/">coupon</a> payments. For shares, it represents the minimum issue price or accounting value.</p>
    <p>Nominal value is distinct from market value, which may be higher or lower depending on supply, demand, and prevailing interest rates.</p>
</section>
<section class="term-section">
    <h2>Why It Matters</h2>
    <p>On Sails.to, nominal value is used to calculate bond yields, coupon payments, and minimum investment amounts. For example, a bond with €100 nominal value and a 6% coupon pays €6 per year per bond.</p>
    <p>Understanding nominal value helps investors compare offerings and calculate their expected returns. The platform displays nominal value clearly in offering terms, alongside current pricing if trading on <a href="/knowledge/glossary/secondary-trading/">secondary markets</a>.</p>
</section>
