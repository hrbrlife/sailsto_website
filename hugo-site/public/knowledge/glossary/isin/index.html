ISIN

A 12-character alphanumeric code that uniquely identifies a security globally, enabling it to be held in traditional bank custody systems.

Full Definition

The International Securities Identification Number is the global standard for identifying securities, administered by national numbering agencies. When a security token receives an ISIN, it can be recognized by traditional financial infrastructure including custodian banks, clearinghouses, and securities depositories. This "TradFi bridge" enables investors to hold tokenized securities in their existing brokerage accounts.

Why It Matters

An ISIN is the key that unlocks institutional adoption. Without it, security tokens exist only in the blockchain world. With an ISIN, your tokens can be held by Clearstream, custodied by traditional banks, and appear in standard portfolio reports.
